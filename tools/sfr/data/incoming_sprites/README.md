Sprites provided by LiderMorti00 for Pokémon Super Emerald, to be converted in Block 4 (Kanto):
- janine_overworld.png / janine_battle.png: Janine (Fuchsia City Gym Leader, as in HGSS)
- karen_overworld.png / karen_battle.png: Karen (Kanto Elite Four)

battle sprites are 80x80 and must be fitted to the 64x64 trainer pic and 16 colours.
